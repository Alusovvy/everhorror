# Everhorror

Polska gra grozy w kopalni (Godot 4.7.2, GDScript): tydzień wyprawy górniczej, ludzie w obozie i tunele pod ziemią. Repozytorium zawiera kod, dane i narzędzia gry; reguły gry i świat opisuje osobna specyfikacja.

Historia wersji (z numerem zgodnej specyfikacji): [CHANGELOG.md](CHANGELOG.md).

Specyfikacja i proces pracy (Roland + agent): [WORKFLOW.md](https://github.com/Alusovvy/everhorror-specification/blob/master/WORKFLOW.md) w repozytorium `everhorror-specification`; lokalnie jako sąsiedni folder `../specification`.

Zadania, arkusze sprawdzeń i ich zasady: [docs/ai-tasks/INFO.md](docs/ai-tasks/INFO.md). Testy, generatory i wydanie buildu: [tools/README.md](tools/README.md). Zasady dla agenta: [CLAUDE.md](CLAUDE.md).
